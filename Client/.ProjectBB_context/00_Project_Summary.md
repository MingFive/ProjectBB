# ProjectBB 项目概述

## 项目定位

ProjectBB 是横屏 2D 小球自动对战肉鸽游戏，玩法概念为“赛博斗蛐蛐”。使用 Unity 2022.3.62f3c1、C#，目标为小游戏平台；具体平台 SDK 与发布链路尚未确定。

项目从零研发。复用 ARPG 的分层思想和经过源码审查的通用模块，不整体复制旧工程，也不延续旧工程的框架迁移任务。

## 已确定的首版设计

- 固定矩形竞技场内，两个敌对小球自主移动。
- 球碰墙、球碰球均按规则反弹；墙体默认不造成伤害。
- 两球每次新接触，双方各产生一次基础碰撞攻击；持续接触不逐帧重复基础伤害。
- 球与技能的有效命中进入统一战斗结算。
- 双方使用同一种小球实体，通过阵营区分，不建立玩家与怪物两套战斗实现。
- 采用固定逻辑步长、自管二维运动、简单几何碰撞；不以动态刚体自由模拟作为首版运动事实源。
- 同一次球体互撞批次完成双方承伤后，再提交死亡；双方同时死亡判平局。
- 吸血鬼采用有最大时长的短暂贴附阶段，之后恢复反弹。
- 横屏正交相机完整展示竞技场，屏幕比例不改变逻辑场地大小。

## 初版数值与表现

以下是制作与调参起点，不是已经经过平衡验证的最终数值：

| 项目 | 起始值或规则 |
| --- | --- |
| 最大生命 | 100 |
| 移速档位 | 100，表示标准速度，不直接等于 100 世界单位/秒 |
| 基础碰撞伤害 | 10 |
| 场地 | 预计 10 × 10 格 |
| 小球 | 直径 1 格，半径 0.5 格 |
| 速度体验 | 约 4 秒走完场地完整对角线，名义速度约 3.54 格/秒 |
| 初始位置 | 左右两侧，球体完整位于场内 |
| 初始方向 | 各自朝向场内，在基准方向 ±45° 内随机 |
| 阵营外观 | A 方红色，B 方蓝色 |
| 伤害飘字 | 小球左上方白色小字，渐隐，数值取实际 HP 扣除量 |

速度标定需明确完整场地对角线与球心可行区域的区别。统一换算后通过试玩调整，不在多个系统重复换算。

## 四种能力验证集

| 小球 | 能力 |
| --- | --- |
| 吸血鬼 | 碰撞触发短暂贴附与减速，期间周期吸血 |
| 一拳超人 | 按战斗时间周期释放范围爆发，初始参考间隔为 5 秒 |
| 提莫 | 撞墙生成毒蘑菇，敌方触发后产生伤害，可附加中毒 |
| 狂战士 | 携带两把旋转斧头，扫过敌方时造成伤害 |

具体倍率、持续时间、数量上限、周期与重复命中间隔待配置和试玩确定。

## 研发顺序

基础双球对战 → 四种能力 → 内容配置与编辑工具 → 多场对战与肉鸽选卡 → 小游戏平台及局外业务。

第一阶段不接操作连招、预输入、NavMesh、NodeCanvas、复杂关卡波次、传送、完整账号背包或热更宿主迁移。
