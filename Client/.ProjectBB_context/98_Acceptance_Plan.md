# ProjectBB 验收计划

## 验收口径

以下均为计划项，未打勾表示尚未通过。文档完成不替代代码实现、Unity 编译、Play Mode 或平台真机验证。每次通过需在 96 中记录环境、操作和结果。

## 阶段 0 工程基线

- [x] 实际 Unity 工程路径明确，存在 Assets、Packages、ProjectSettings，版本符合要求。2026-10-10 文件核对通过，见 96 的 DEV-001；不包含运行验收。
- [ ] 最小场景启动、退出、重复 Play 无错误，无重复初始化和残留对象。
- [ ] Runtime/Editor 依赖分离，没有为首版引入无用的 AI、寻路、热更宿主。
- [ ] 选定小游戏平台后尽早完成最小构建验证；不能仅以 Editor 能运行证明平台可用。

## 阶段 1 运动与接触

- [ ] 场地尺寸固定，球体出生位置在边界内，左右各自朝场内 ±45° 随机出发。
- [ ] 无修正时速度稳定，减速生效后反弹不会恢复原速。
- [ ] 正面、擦边、角落、不同速度及零速条件下运动正常。
- [ ] 高速、小步多次反弹和初始重叠不穿墙、不穿球、不无限循环。
- [ ] 同一次接触只产生一个基础双向批次，Stay 不重复扣血；真正分离后重撞可再次伤害。
- [ ] 免疫伤害不阻断反弹；墙体默认不扣血；普通技能检测不产生无配置推挤。
- [ ] 同时撞到两条墙边按一次撞击触发能力，不重复生成。

## 阶段 1 伤害与流程

- [ ] 100 HP、基础伤害 10 时，无修正碰撞双方各损失 10。
- [ ] 双方各 5 HP、伤害各 10 时平局；交换实体注册/遍历顺序不改变结果。
- [ ] 单方免疫、双向不同伤害和过量伤害正确，死亡与胜负各只提交一次。
- [ ] 暂停同时停止运动、技能、Buff、周期伤害和战斗计时，UI 仍可交互。
- [ ] 切换渲染帧率时战斗周期不按帧率加快或变慢；同一运行环境固定输入可诊断复现。
- [ ] 重复重开、退出、恢复前台无旧会话回调、重复订阅或离线补伤害。
- [ ] 战斗结束后旧攻击请求不再造成伤害；运行上限与超时策略在实施时明确并验证。

## 阶段 2 吸血鬼

- [ ] 基础碰撞批次完成后，存活双方进入有上限的贴附，不依靠偶然重叠维持吸血。
- [ ] 周期吸血只在有效关系内发生，基础碰撞伤害不随 Stay 重复。
- [ ] 吸血按实际 HP 损失计算；护盾吸收、免疫、过量伤害和满血不会错误治疗。
- [ ] 同批次致死不能被事后吸血自动复活。
- [ ] 贴附到期、死亡、能力移除、强制位移、退出均能解除，仅移除本来源减速。
- [ ] 双吸血鬼只维护一个运动关系，各自周期独立且不能无限刷新关系。

## 阶段 2 其他能力

- [ ] 一拳超人按配置战斗时间周期释放，每次范围攻击对目标只命中一次，暂停不累计。
- [ ] 提莫撞墙生成位置在场内，连续/角落撞击去重，数量和寿命有上限。
- [ ] 蘑菇按明确触发规则消耗，伤害通过独立技能与统一承伤，免疫目标的消耗规则已明确。
- [ ] 中毒伤害模型、首末跳、重复施加和来源归属有明确配置与验收。
- [ ] 狂战士有两把独立斧头，高速旋转扫过不漏判，不逐帧重复命中，也不吞掉另一把合法命中。
- [ ] 移除能力、死亡、重开后无遗留斧头、蘑菇、计时任务或修改器。
- [ ] 四种球包含同类型对战在内能够组合运行；派生触发有预算且不无限递归。

## 阶段 3 配置与工具

- [ ] 配置错误定位到表和引用，覆盖重复 ID、缺失技能、非法周期、半径和出生点。
- [ ] JSON 与 SO 不被运行实例和 Trait 修改；重复启动不会累积污染配置。
- [ ] 编辑器预览与运行时一致使用 XY、Z 轴旋转、二维锚点和范围。
- [ ] 时间线跨片段、暂停、结束与取消不漏必要事件、不重复执行。
- [ ] 增加同类小球可通过配置组合完成，不为每张普通属性卡新增类。

## 阶段 4 肉鸽

- [ ] 明确整次尝试与单场对战状态，构筑跨场保留，接触和技能物不泄漏。
- [ ] 候选生成、选择合法性、重复选择幂等、旧批次拒绝和投影顺序通过。
- [ ] 卡牌获得、升级、移除正确应用和撤销 Trait/属性来源。
- [ ] 明确并验证跨场 HP、Buff、冷却与失败/重开规则。

## 表现与平台

- [ ] 横屏不同宽高比、安全区下场地完整可见，逻辑尺寸保持不变。
- [ ] 红蓝球、血条、白色左上飘字正确，展示实际 HP 扣除值，受击缩放不改碰撞体积。
- [ ] 分层图片与序列帧在实际战斗尺寸下清晰，切帧无枢轴跳动、遮挡错误；身体形变不拉伸血条或改变武器轨道。
- [ ] 待机、碰撞、连续受击、施法与死亡反馈组合正常，无属性争写；动画不影响逻辑位置、半径、命中与死亡结算。
- [ ] 战斗动作、序列帧与特效响应暂停和倍速，切换渲染帧率不改变播放时长；重开和池化复用无残留帧、颜色、缩放或旧回调。
- [ ] 实际目标设备测帧率、CPU、GC、内存、透明叠加、粒子、加载和包体，记录设备与场景。
- [ ] 最大技能物与飘字压力、重复进出、前后台切换不泄漏，资源归属与释放明确。

性能目标和数量预算待实际平台与设备确定，不把旧 ARPG 性能结论直接作为本项目通过证据。
