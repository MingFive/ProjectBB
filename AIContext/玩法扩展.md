你的方案很适合做成**“战前搭配、战中自动碰撞”的观战型对战游戏**。扩展空间很大，尤其值得设计的是：**让不同小球以不同方式利用碰撞、墙壁和运动轨迹，从而产生能看懂、能搭配、能克制的战术。**

我读完了 TXT，里面已经有碰撞伤害、四种角色思路，以及后续 3v3 和 Boss 的方向。当前工作目录里没有找到 `AGENTS.md`，也没有项目代码，下面先讨论玩法和框架设计，不假设现有实现。

**首先，要把基础物理规则和技能改变的规则分清楚。**

你说的“动量守恒、质量固定”，可以作为普通球体碰撞的基础，但有几个区别：

- **球与球碰撞：**不受外力的碰撞过程中，两球总动量守恒。如果还要求动能不损失，就采用完全弹性碰撞。
- **球与固定墙碰撞：**墙给球施加冲量，因此只看两个球，它们的总动量不守恒；普通墙可以设计为不损失速度大小的镜面反射。
- **质量固定不等于速度固定：**如果两个等质量球正面碰撞，可以交换速度；斜向碰撞时，两球各自的速度大小可能变化。每次碰完强行恢复固定速度，会改变原本的物理结果。
- **技能可以主动改变运动：**减速、冲刺、吸引都可以存在，只需明确它们是技能施加的额外作用。

建议采用一个原则：**普通碰撞规则稳定，技能明确地改变其中某一项。**玩家才能逐渐理解“为什么这次赢了”。

下面这些方向，比较适合你的核心玩法。

**1. 让碰撞本身具有不同的价值**

目前“碰一次，双方各扣 10 血”容易变成主要比较碰撞次数。可以让碰撞的条件影响收益。

| 扩展点 | 具体设计 | 带来的玩法 |
|---|---|---|
| 撞击强度 | 根据碰撞法线方向的相对接近速度，给予额外伤害 | 正面高速撞击更有威胁，擦边收益较小 |
| 碰撞朝向 | 正面有盾，侧面和背面承伤更高 | 出现绕侧、改变朝向、旋转护盾等机制 |
| 连续碰撞 | 短时间内连续命中可以叠连击，离开后重置 | 鼓励贴身缠斗 |
| 蓄力碰撞 | 一段时间没撞到敌人，下一撞逐渐增强 | 与贴身流形成不同节奏 |
| 攻守窗口 | 护盾周期性开启，撞击收益随时间变化 | 同一条轨迹，在不同时间产生不同结果 |
| 碰墙联动 | 撞墙后短暂强化下一次撞击 | 墙壁成为战斗资源 |

这里有个关键细节：**伤害强度应优先看“迎面撞得有多狠”，而不是只看某个球跑得有多快。**两个高速同向移动的球，轻轻追尾不应该等同于迎面相撞。

第一版可以保留固定 10 点伤害，只挑一两个角色使用速度或角度机制，降低理解成本。

**2. 把墙壁和地图变成参与战斗的机制**

方形场地已经足够承载很多玩法，不必一开始就做复杂地图。

| 场地机制 | 对运动的影响 | 可以形成的战术 |
|---|---|---|
| 弹力墙 | 碰撞后额外提供速度 | 利用墙壁加速进攻 |
| 阻尼墙 | 碰撞后损失部分速度 | 克制依赖高速的角色 |
| 充能墙 | 普通反弹，同时获得技能资源 | 鼓励频繁利用场地边缘 |
| 单向流场 | 在区域内持续受到某方向的力 | 改变进攻路线、制造追击 |
| 中央障碍 | 增加反弹路径和遮挡 | 绕行、埋伏、限制远程攻击 |
| 成对传送门 | 改变位置，按明确规则转换速度方向 | 形成突袭和特殊循环路线 |
| 移动挡板 | 挡板运动参与碰撞，可向球传递能量 | 定时制造强撞击 |
| 收缩边界 | 随时间压缩可活动空间 | 加快后期接战，结束拖延局 |

建议初期每张地图只突出一个机制。例如：

**普通方形场地 → 左右充能墙 → 中央障碍 → 后期收缩场地。**

地图机制过多时，玩家很难判断胜负来自角色搭配，还是场地偶然事件。

**3. 用“不同的运动诉求”区分角色**

你文档里的角色方向不错，但可以再明确：每个角色希望战斗变成什么样。

| 角色方向 | 希望出现的战斗局面 | 主要机制与制约 |
|---|---|---|
| 重击型 | 长距离助跑后正面相撞 | 高速撞击更强，被减速后收益下降 |
| 吸血型 | 敌人长时间停留在附近 | 近距离持续吸血，害怕击退和脱离 |
| 布雷型 | 反复经过墙边，让对手进入布置区域 | 碰墙布雷，但有数量与存续时间限制 |
| 旋刃型 | 敌人进入外围武器的攻击距离 | 擦身也能攻击，受武器转速与攻击间隔限制 |
| 蓄力型 | 一段时间避免碰撞，等下一次强撞 | 怕高频小碰撞消耗蓄力机会 |
| 反击型 | 在防御窗口内被撞击 | 吸收冲击后反击，存在明显空窗 |
| 引力型 | 让对方偏离原轨迹、进入危险位置 | 操控路线，但直接伤害较低 |

这样角色差异会同时体现在**轨迹、接战频率和伤害节奏**上，而不只是技能特效。

你现有四个设想，有几个值得提前调整的地方：

- **吸血鬼：**降低速度不一定会让两个有反弹的小球持续接触。可以改为“碰撞后产生短暂吸血范围”，敌人在范围内就持续吸血；如果确实需要粘连，则把粘连做成明确技能状态。
- **一拳超人：**每 5 秒直接范围爆炸，更像定时炸弹。若想突出“一拳”，可以改为每 5 秒准备一次强化撞击，命中后释放，并提前显示蓄力效果。
- **提莫：**蘑菇需要数量上限、持续时间、生成间隔，以及相邻位置是否允许重叠的规则，否则很容易演变成无限铺场。
- **狂战士：**斧头建议先作为伤害判定区域，让球体负责主要反弹。若斧头也参与实体碰撞，它就会同时改变运动轨迹，复杂度明显增加。

**4. 给玩家能够影响结果的选择**

如果战斗基本自动进行，游戏深度主要来自战前决策。建议先选择少量、但能明显影响战斗的操作：

| 玩家选择 | 决策价值 |
|---|---|
| 出生位置与初始方向 | 决定开局抢中央、先碰墙，还是立即接战 |
| 一个主技能与一个被动 | 形成清晰的搭配，例如“碰墙充能＋蓄力撞击” |
| 战前选择强化路线 | 在速度、攻击范围、技能频率之间取舍 |
| 3v3 阵容与站位 | 组合控场、输出、保护角色 |

你文档里是初始角度在 ±45° 内随机。这个设定可以制造变化，但建议让随机性可控：例如玩家选择大致方向，再给予小范围扰动。

如果希望增加少量即时操作，可以加入**每局有限次数的冲刺或护盾**。先只选一种，避免自动观战与频繁操作之间定位不清。

**5. 物理框架应当预留哪些扩展位置**

从设计上，建议把职责分开。下面是系统边界建议，不代表需要立刻做成复杂框架。

| 系统 | 负责什么 | 扩展时的影响 |
|---|---|---|
| 运动与碰撞 | 位置、速度、质量、形状、反弹、外力 | 新增地图材质或运动能力主要影响这里 |
| 接触信息 | 谁碰到谁、接触位置、方向、相对速度，以及开始接触和结束接触 | 为伤害和技能提供统一依据 |
| 战斗结算 | 伤害、护盾、治疗、死亡、阵营关系 | 调整数值不应直接改动碰撞求解 |
| 能力与状态 | 碰墙触发、周期触发、减速、吸引、强化攻击 | 新角色尽量组合已有能力 |
| 场地与规则 | 墙体属性、机关、出生点、胜负、超时 | 支持不同地图和比赛模式 |
| 表现与记录 | 特效、音效、飘字、战斗统计 | 帮助玩家理解效果、帮助开发定位问题 |

最值得配置化的，是技能的四个组成部分：

**触发时机 → 生效条件 → 作用目标 → 产生效果。**

例如，你的布雷技能就可以描述为：

> 碰到墙壁 → 生成间隔已满足且数量未达上限 → 当前接触位置 → 放置有持续时间的毒蘑菇。

以后把“碰到墙壁”换成“护盾被打破”，就能产生另一种角色能力，而不必重新设计整套逻辑。不过，第一版只支持实际用到的组合即可。

还有几条规则，最好在底层尽早明确：

- **实体碰撞与伤害判定分开。**球体负责反弹，毒区、武器范围等可以只产生战斗效果。
- **一次撞击与持续接触分开。**普通撞击结算一次；持续伤害按照独立间隔结算，避免每个物理步都扣血。
- **同次碰撞的双方结果统一处理。**支持同归于尽，避免谁先执行伤害谁就获胜。
- **为高速和异常状态设置边界。**包括高速穿透、角落抖动、低速停滞，以及同一瞬间触发过多效果。
- **提前支持多个单位。**碰撞双方按单位身份、阵营和属性判断，不把逻辑写死成“红球”和“蓝球”，方便未来 3v3 和 Boss。

**我建议你的第一轮扩展，只做三个鲜明角色和两种地图：**

1. **重击球：**验证速度如何影响撞击收益。
2. **吸血球：**验证近距离持续作用与脱离机制。
3. **布雷球：**验证碰墙触发、场地物件和空间控制。
4. **普通方形地图：**作为比较角色强弱的基准。
5. **带中央障碍的地图：**验证改变路线是否真的改变角色优势。

这组内容已经能检验直接撞击、持续效果、场地布置三条扩展路线。观察每场战斗时，重点看：**玩家能否看懂胜负原因，以及换一个搭配或初始方向，是否有理由期待不同结果。**
